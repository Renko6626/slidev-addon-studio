# 人机协同制作样例

复制整个目录到工程外的可写位置，运行 `pnpm install` 和 `pnpm dev`。依赖使用随此样例发布的 Studio 版本；发布前验证时可将 addon 依赖临时指向准备好的 tgz。不要直接修改 node_modules 中的样例。

第一页展示两种编辑边界：标题/说明是独立文本框，图文卡片整体移动，内部文字和图片通过字段编辑。卡片光效由组件实现，只在当前播放页运行。第二、三页复用内置判题与正确次数，不另建计分状态。

在 Studio 中：

- 拖动标题、说明或整张卡片；外框和旋转保存在 slides.md 的 v-drag。
- 双击卡片文字修改内容；通过属性面板替换图片和调整主色。
- 从“插入 → 素材”添加自己的图片、音频、视频；音视频默认手动播放，可在属性中设置自动播放、循环、音量和起播时间。
- 预览并答题，切到下一页仍能看到首次答对的题目数。回到编辑后开始新试播。

`GuestSpotlight.vue` 中的光效、内部排版及业务代码由 agent 修改。人可以独立移动标题，不能把卡片内部图片拆成独立图层；需要这种自由度时让 agent 改成多个页面对象。

第四页提供自生成的短 MP4 色块视频和 WAV 提示音，无第三方素材。两者默认手动播放；选中后可替换成自己的文件。没有网络服务或自动转码。素材兼容范围见安装包 `docs/custom-code/media.md`；命令构建不能代替现场播放确认。
