# 内置 SVG 图形

用户已确认方案二：项目携带内置 StudioShape Vue 基础组件，文稿以简短组件标签和参数保存。以编辑方便为优先。本轮实施常见预制图形和符合类型语义的手柄；多边形顶点编辑后续做。

## 已选路线
标准 SVG 加编辑参数的路线会增加生成结果同步和文稿长度；用户选择 Vue 组件标签，接受放映依赖随 addon 提供的基础组件。沿用 Vue、Slidev、v-drag、现有 Markdown 保存和撤销，不增加绘图库、服务或数据库。

## 范围
- 矩形、圆角矩形、椭圆、三角形、菱形、六边形、直线、单向/双向线箭头、块状箭头。
- 插入菜单选择后画布拖拽绘制，轻点插入默认尺寸；Esc 取消。插入后选中。
- 封闭图形使用既有外框缩放、旋转、移动/吸附；Shift 等比。直线/线箭头使用两端点手柄，另一端固定，Shift 对齐 45 度方向；整体移动仍复用原手势。
- 圆角、块状箭头头部和杆宽有专用调整点；属性面板提供填充、描边、线宽、虚线及适用参数。图形缩放不改变设定线宽。
- 拖动即时显示，松手一次提交；Esc 取消当前手势。复制、删除、层级与历史复用原操作。
- 任意 SVG 导入编辑、顶点/贝塞尔、自动连接线、多选组合和图形内文字不在本轮。

## 实现边界
- components/StudioShape.vue 是随 addon 发布的放映组件，仅依赖 Vue、现有 VueUse 和 shared/shapes.ts；不引用编辑器上下文。根据根元素实际尺寸绘图，响应 v-drag 改变外框。
- shared/shapes.ts 提供参数归一化、路径、端点/外框转换与形状调整数学。线段用横向局部坐标，外框高度 16，长度和旋转表达任意方向，避免零高选框。
- client/md/shapes.ts 在现有标签属性读写器上保存 props，位置只存在 v-drag；无额外持久对象 ID。生成标签在文稿中作为独立组件块。
- 专用手势通过组件 DOM 上临时预览事件传递参数；只在手势中使用，不建立第二套持久状态。完成后现有渲染应用源码 props。
- 插入、属性和手柄使用专用小模块，通用 gizmo 只做必要兼容；不把文字或普通组件迁移到新模型。
