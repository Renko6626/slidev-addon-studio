# 选择题选项增删

用户已确认：在题目属性面板增删选项，默认仍为四项，沿用现有组件与数据结构。

考虑过插入时指定数量，但它无法解决已有题目的编辑，因此采用面板增删。
添加时分配未使用的字母编号并创建 StudioButton；删除时移除该规则与同题同选项的内置选项按钮。保留其他编号、内容、样式和位置。
新按钮放在画布中央，用户自行拖动。正确答案由用户显式标记，不因删除擅自替换答案。
每次操作只提交一次 Markdown，复用现有撤销历史。自定义组件和动态源码仍由 coding agent/作者维护，不增加通用组件改写机制。
不增加依赖、接口、存储字段或自动排版系统。仅相关测试与类型检查，不运行浏览器交互测试。

用户要求三层顶栏合一，并确认采用 Electron 原生窗口按钮叠加：`titleBarStyle: hidden` 配合 `titleBarOverlay`，移除独立原生菜单。保留新建、打开、另存、编辑和保存快捷键，日志移到 Studio 文件页；欢迎页和非全屏预览仍有拖动区域，预览内容为标题栏留出空间。完全自绘窗口按钮维护更多，未采用。

文件页的项目路径可以打开当前项目根目录。增加“让 coding agent 去这里改”的工作目录提示和已安装 addon 内相对 skill 路径。沿用已有桌面工程操作桥接，不接受任意路径参数。
