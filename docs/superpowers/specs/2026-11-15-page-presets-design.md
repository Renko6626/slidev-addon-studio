# 基础插入与新建页版式

用户已确认先整理基础插入、提供新建页版式与对应预览，并要求直接实施。

方案：保留现有编辑器与源码格式，新增空白、标题页、标题和正文、两栏内容、左图右文、右图左文、全屏图片七种页面预设。预览与生成使用同一组对象坐标；文字使用 Studio 文本框，图片占位使用可替换的 Studio 图片。使用现有 deck insert 的 content/frontmatter 参数，无新接口、依赖或数据存储。

新建页的顶部和左侧入口打开同一个版式库；选择后在当前页后插入。旧 layout 设置标为高级布局，说明不自动搬移已有对象。基础插入以标题文本框、正文文本框、图片和形状为主，组件库只保留代码与引用等扩展块，移除重复基础条目和双栏结构。

取舍：只改名称不能解决插入后难编辑的问题；完整模板体系与已有内容自动重排超出本轮。图片占位由内嵌 SVG 提供，不依赖外链或不存在的素材，通过已有更换图片操作替换。沿用原界面样式与中英文翻译。

验证：关键行为覆盖生成对象可编辑、图片可替换且保留位置、不同画布比例与空白页。集中运行已有测试、类型检查及构建；浏览器最多截图，不自动交互。不发布，不覆盖工作区已有改动。
