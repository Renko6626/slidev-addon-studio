# 独立题目管理控件

用户已确认：题目是独立逻辑控件，编辑时显示管理节点，虚线表示它与题干、选项、操作按钮、反馈的关联。播放时默认隐藏管理节点，可开启简短题目信息显示；编辑按钮和关联线始终仅用于编辑。

## 路线与取舍

- 采用现有 `StudioQuestion` 作为配置和运行注册节点，新增 `StudioQuestionTitle` 显示题干，现有按钮/反馈继续按 `question` ID 关联。沿用 Vue、Slidev、Markdown 和当前运行实例，无新依赖、数据库或第二份文稿模型。
- 页级 frontmatter 配置归属清楚，但需另建管理入口与运行配置读取；当前选用可选中、可定位的管理节点，以直接呈现用户提出的逻辑控件。
- 子组件为独立自由定位对象，不引入父容器、永久组合、自动连带移动、连线编辑或流程编排。

## 行为

- `StudioQuestion` 使用 `presentation: 'hidden' | 'summary'` 和 `name`。默认 `hidden`，编辑时显示管理节点；`summary` 在播放时显示名称。用户明确项目处于早期阶段，直接采用统一的新结构，不保留旧版题干呈现、兼容分支或迁移逻辑。
- 管理节点持有题干、选项/答案、反馈配置。题干组件仅引用题目并显示其题干，编辑题干写回对应配置。删除题干不注销题目。
- 管理节点的可见性不影响注册。运行层继续独立于编辑器，无论隐藏与否都可答题。配置使用现有运行状态与会话重置规则。
- 管理节点属性展示名称、播放显示开关和整题配置；关联组件展示所属题目并提供定位到题目控件的入口。管理节点不进入文字编辑。
- 选中管理节点时显示所有直接关联线；选中子组件时仅显示其与管理节点的线。连线从当前页 DOM 和 ID 派生，忽略鼠标，不写入源码。多选和文字编辑时隐藏。
- 复制包含管理节点的集合时重命名题目 ID，同时更新题干/按钮/反馈；单独复制子组件保留原关联。
- 删除管理节点前提示：仅删除管理节点，保留关联组件，但它们无法继续答题；可通过已有撤销恢复。无自动级联删除。

## 验证边界

复用现有测试与 SFC 加载工具，只补充隐藏控件仍能运行、删除题干保留配置、题干写回和集合复制关联等关键行为。集中运行现有检查与静态构建。浏览器仅导航、只读检查及截图，不自动点击/输入/答题。无发布、打包、推送授权。
