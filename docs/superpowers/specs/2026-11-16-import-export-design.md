# Studio 导入导出

用户已确认：接入现有 PDF、PNG、图片型 PPTX 导出，保留工程 ZIP 导出，桌面端增加工程 ZIP 导入；修复文件名被挤成单字换行的问题。

## 方案与取舍

采用现有 Slidev 52.19 浏览器导出页，先保存，再打开导出页选择格式、页码和点击步骤。桌面端借已有外部链接处理器在系统浏览器打开，避免新增 Electron 屏幕采集权限及实现。PDF 使用浏览器打印，PNG 为上游提供的压缩包，PPTX 每页为图片。禁用 browserExporter 的工程显示说明。

另一方案是增加服务端 CLI 转换接口及浏览器依赖，维护成本更高；原生可编辑 PPTX 双向转换需要独立设计，本轮不做。没有新依赖、转换服务、任务队列或网络服务。

桌面 ZIP 导入复用现有归档路径验证与解包，用户选择 ZIP 和空目录，再按打开工程的既有流程选择 Markdown 入口、检查环境及安装依赖。保留工程内容与已有版本，不新增工程清单格式。旧宿主没有导入能力时不显示入口。

文件页标题行的刷新按钮继承了通用按钮 width:100%，且禁止收缩，挤压项目名称。改为内容宽度并给名称剩余空间；文件树名称保持单行省略，悬停保留完整路径。

本轮不修改 Markdown/Vue/TS 源码编辑边界，不发布或更新安装包。
