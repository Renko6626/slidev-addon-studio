# 按钮与选择题交互首版

用户确认：普通制作使用可复用逻辑模块及界面配置；JS/Vue/Markdown 编辑属于高级功能。先做单选、多选两套模板，按钮经过统一信号入口，支持重复作答。生命周期采用同次试播切页保留、离页停止活动，结束试播后重置。

## 已选方案

使用已有 Vue/Slidev 和源码写回。`StudioQuestion` 保存题目配置并显示题干，`StudioButton` 保存题目/动作绑定并独立定位，`StudioFeedback` 显示结果；全都以普通组件调用和静态 props 保存在 Markdown。不创建第二份文稿数据、后台、联网协议或任意脚本执行器。相比每题独立 JS，复用逻辑避免状态规则分叉；相比通用流程编排器，首版仅提供两种明确题型。

题目配置包括当前页内唯一标识、题型、题干、选项（id/label/correct）、反馈文案。运行状态包括当前选择、判定、提交次数，不写回源码。页面/缩略图使用不同运行实例，只有主放映画面当前页且非编辑模式接收动作。编辑画布、缩略图、组件预览不执行答题。

## 交互合同

`QuizMode = 'single' | 'multiple'`；`QuizOption = { id: string, label: string, correct: boolean }`。

组件 props：
- `StudioQuestion`: `question`, `mode`, `title`, `options`, `correctText`, `incorrectText`, `idleText`。渲染单个可定位题干根节点；同页按钮通过 `question` 查到配置和状态。
- `StudioButton`: `question`, `action`, `option?`, `label?`, `fill?`, `color?`, `selectedFill?`, `correctFill?`, `incorrectFill?`, `radius?`。无 label 的选项按钮显示配置中的选项文字；确认/清空按钮显式设置 label。单根 button，题干/按钮文本所在节点带 `data-studio-interaction-text`，供普通文字编辑定位。
- `StudioFeedback`: `question`, `effect?: 'none' | 'fade' | 'pop'`。反馈文案来自题目，默认简单淡入，正确/错误状态可见。单根可定位组件。

信号 `QuizSignal`：`{ question, action: 'choose', option }`、`{ question, action: 'set-option', option, selected }`、`{ question, action: 'submit' }`、`{ question, action: 'clear-pending' }`。鼠标只转换为该信号，外部代码可调用同一分发入口。未激活页拒绝，不广播所有题目、不排队。多选按钮根据现状态生成显式 selected 值。

单选选择即判断，每次可重新选。多选变更撤掉旧判定，提交按正确选项集合完全相等判断；清空移除选择和反馈。没有选项时提交不判题。结果供按钮样式和反馈效果读取。无部分得分、跨页计分、计时器或远程控制首版实现。

## 编辑体验

“插入”提供单选题页、多选题页及独立按钮入口。模板新增一页，包含题干、默认四个选项、反馈，多选另有确认/清空按钮。初始位置已排好，分别可移动/缩放；配置在右侧完成，不显示原始事件名或要求填写 JS。题干/选项/按钮双击进入简单文字编辑；复杂代码仍在高级源码。

按钮属性显示所属题目、可用动作、选项及外观。可预览普通/选中/正确/错误外观，该预览不修改实际答题状态。题目参数可修改选项文字和正确答案，优先复用现有字段。新增/删除选项若提供，须同步其绑定按钮，不能留下无意义条目。

同页题目标识明确且不绑定行号。复制整页天然独立；单独复制按钮仍绑定同页原题；复制包含题目配置的对象集合时重新分配题目标识，并更新集合内相关按钮/反馈引用。使用既有剪贴板结构，不引入新协议。

## 生命周期及边界

主页面实例激活时接收动作，切页保留数据但不接收输入。进入/退出 Studio 编辑模式切换试播会话并重置；缩略图/预览下一页/演讲者辅助画面不单独判题。纯静态放映无需编辑器代码仍可工作。任意第三方 JS 不自动托管；自定义扩展通过公开动作/状态接口使用。

## 验证

短小生产逻辑测试覆盖两种判定/重试/重置、实例隔离、生命周期、信号入口、源码配置和复制关联。复用已有选择与写回检查。集中运行测试、TS/Vue检查、真实模板静态构建。浏览器最多导航截图/只读检查，不自动点击、填写、拖动或答题流程。无推送、发布或打包授权。
