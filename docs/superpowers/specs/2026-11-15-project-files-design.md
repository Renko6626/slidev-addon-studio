# Studio 项目与“文件”入口

用户已确认：首版采用标准 Slidev 目录工程、沿用自动写回、增加“文件”选项卡及项目信息、提供工程 ZIP 导出；先写计划，再直接实施。

## 行为与边界

- 工程根目录为入口文件最近的 `package.json` 所在目录；没有时使用入口目录。不能直接将整个 monorepo 工作区视为工程。入口保持原路径，允许入口位于子目录。
- 工程不要求 `.git`、账号或 `project.yaml`。目录中已有的 Markdown、素材、组件、样式、锁文件和补丁原样保留。
- “文件”在功能区最左侧，打开独立的文件页，提供项目信息、只读目录列表、保存和工程 ZIP 下载，以及返回编辑器。
- 文件页保留工程名称、根目录和入口的区别；根目录属于当前 Slidev 服务所在机器，不能误称为用户电脑路径。
- 保存保持自动写回。显式保存及 Ctrl/Cmd+S 应用当前文字编辑，提交备注输入，并以实际写入结果显示保存中、已保存、编辑未应用或写入失败。不能仅因请求结束就显示成功。
- 下载工程前先应用当前编辑、完成当前写入；失败时停止下载并保留可见错误。ZIP 来自磁盘现状，包含未提交、新增源码和二进制素材，不调用 git archive。
- ZIP 保留工程内部相对路径；排除依赖目录、Git 元数据、构建缓存、编辑器工作目录、`.env` 实值文件、`.npmrc` 等本机凭据配置。保留 `.gitignore` 和 `.env.example` 等示例文件。
- 源文件符号链接或跨工程的幻灯片源码不能静默漏打包；显示具体路径并要求用户先将文件放入工程。首版不增加链接恢复、依赖搬运或外部资源抓取机制。
- 小规模低频使用，采用内存 ZIP；复用依赖树已有的 JSZip 3.10.1，并声明为直接依赖。不新增导出任务队列、数据库、恢复状态机或依赖安装机制。
- 新建、打开、另存及切换属于网站或桌面宿主；本轮没有可调用的宿主，文件页用简短说明交代，避免放置无行为的操作按钮。
- 不新增通用源文件编辑器，不实施 PDF/PPTX/演示网页导出、Electron 打包、网站协作或同步改造。

## 方案取舍

采用目录作为编辑来源、ZIP 作为传递副本，便于普通 Slidev CLI、代码编辑器及 agent 接续使用。压缩包直接编辑需要解压、回写及额外文档生命周期，暂不采用。自动写回沿用已确认行为，避免为手动保存另建文档副本。

## 验证

新增少量行为测试覆盖工程根识别、真实 ZIP 内容及排除规则、导出拒绝外部源码、保存成功/失败及未应用编辑。复用现有测试框架和真实临时文件。最终集中运行现有测试、TypeScript 检查、Slidev 静态构建；临时工程执行根路径与挂载路径 HTTP 导出探针。UI 默认只作编译检查及可用时截图，不执行自动点击、输入或交互流程。
