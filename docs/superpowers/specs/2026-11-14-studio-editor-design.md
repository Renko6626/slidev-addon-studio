# Studio 完整编辑模式

日期：2026-11-14

状态：用户于 2026-11-15 确认首版设计，并要求先参考标准 Microsoft PowerPoint UI。以下已纳入官方界面资料对照后的布局与命令组织细化，保持已确认的技术路线及功能边界。

## 目标与已确认边界

把 Renko fork 中的 Studio 从演示页面上的辅助面板，改成接近 PowerPoint 使用方式的完整编辑界面。用户可以持续看到整套文稿的页面，在画布上编辑当前页，通过顶部命令与右侧属性完成制作。

用户已选择 B 路线：在现有 addon 内修改。沿用 Vue、TypeScript、Slidev 渲染、现有 Markdown 写回和本地素材目录。Markdown 仍是文稿内容来源，普通 Slidev 工程即可使用。

Studio 只负责编辑器能力，不接入 Git、分支、同步、审核、工作台身份、项目管理或工作台后端。现有工作台继续作为外部入口；本次不修改它的代码。未来可以另行选择本地应用的打包方式，本次不引入 Electron、Tauri、新进程管理层或桌面专用接口。

## 方案比较

| 方案 | 做法与取舍 | 结论 |
| --- | --- | --- |
| A 调整现有布局 | 页面面板移到左侧，固定工具条；改动少，但仍以演示页面和单一面板切换为中心 | 未选择 |
| B addon 内完整编辑模式 | 重组外壳，复用现有渲染和编辑能力；主要工作是画布布局与功能入口 | 用户已选择 |
| C 独立编辑器应用 | 单独外壳与 Slidev 运行环境连接；自由度更高，也增加状态同步与集成边界 | 当前不需要 |

## 首版界面

```text
┌────────────────────────────────────────────────────────────┐
│ 文稿名称                  撤销 重做             预览 放映   │
├────────────────────────────────────────────────────────────┤
│ 开始    插入    设计    切换    动画    视图    [对象]        │
│ 当前分类下的命令，按操作目的分组                            │
├───────────┬───────────────────────────────┬────────────────┤
│ 页面      │                               │ 属性           │
│ 1 缩略图  │                               │                │
│ 2 缩略图  │          当前幻灯片           │ 当前选中元素   │
│ 3 缩略图  │                               │ 或页面的设置   │
│ …         │                               │                │
│ ＋新建页  ├───────────────────────────────┤                │
│           │ 备注，可展开和收起            │                │
├───────────┴───────────────────────────────┴────────────────┤
│ 第 2 / 18 页       备注                     比例  适应窗口  │
└────────────────────────────────────────────────────────────┘
```

顶部采用文稿栏、分类标签、分组命令三层结构，命令区保持紧凑。常用动作直接执行；附加选项放入相关下拉菜单；详细参数在右侧展开。分类标签切换顶部命令，不能退化成原有六个面板的横向入口。左栏、右栏和画布拥有各自的滚动或布局区域；页面列表不会因为查看元素属性或插入素材而消失。

首版沿用 Studio 的深色、中性色和蓝色选中反馈，减少悬浮阴影与装饰性圆角，使用已有系统字体。新增文字同时提供简体中文和英文。浅色主题及完整视觉换肤不在首版范围。

### 左侧页面列表

复用 `PanelSlides` 的页面跳转、新增、复制、删除、拖动排序，以及 `SlideThumbnail` 的真实渲染。列表常驻左侧，以缩略图为主要视觉内容，页码放在缩略图外侧，标题仅作次要信息；当前页使用清晰边框，滚动区域应能定位当前页。缩略图大小匹配左栏可用宽度，不继续固定为当前右侧列表使用的 132 像素。操作按钮在选中、悬停或键盘聚焦时出现，避免每页常驻一排工具；右键保留为辅助操作，常用动作必须有可见入口。

首版保留现有缩略图的第 0 个点击步骤，动态内容的后续步骤在动画面板或预览中查看。暂不增加截图缓存、缩略图渲染服务、隐藏页管理或跨文件排序。

### 顶部命令区

| 分类 | 首版命令 |
| --- | --- |
| 开始 | 幻灯片组：新增页、复制页、删除页、版式入口；编辑组：选中元素的编辑文字、复制和删除 |
| 插入 | 标题、正文、列表等已有基础块；打开组件库和素材库 |
| 设计 | 页面背景和布局参数；复用现有布局缩略图与表单，版式入口与开始页共用同一操作 |
| 切换 | 当前页的已有页面切换效果，保持 Slidev 的离开当前页语义 |
| 动画 | 当前页点击步骤和选中元素的已有动画效果，详细设置通过动画面板进入 |
| 视图 | 网格、吸附、元素轮廓、侧栏和备注显隐、适应窗口 |
| 对象（仅有选中对象时） | 自由定位、返回文档流、现有顺序调整、位置尺寸属性入口；按对象实际支持的能力显示或禁用 |

撤销和重做固定可见。对象操作与页面操作必须有明确名称，避免用户误删整页。对象上下文标签出现时不强制抢走用户正在使用的分类；取消选择后移除该标签，若当前正使用它则回到开始。首版使用统一的“对象”标签，不为图片、形状等创建没有真实功能支撑的专用格式标签。

已支持但当前不可用的常用命令保留位置并禁用；尚未实现的功能不显示。现有顺序调整改变 Markdown 块或列表项的顺序，不等同于通用图层管理，不使用“置于顶层”“置于底层”等名称。页面切换复用现有 `transition` 写回，不改成 PowerPoint 的切入当前页语义。

基础块插入复用现有片段与写回逻辑；组件和素材目录以顶部入口打开的临时面板展示，保持左侧列表及右侧属性可用。组件插入成功后关闭目录并查看新对象属性；素材沿用现有选择与插入能力，不顺带承诺新的对象追踪机制。

文字的加粗、斜体等格式操作首版保留在已有原位工具条，避免在外壳更新中重做文字选区管理。字体、字号、段落对齐、原生图形库不在首版新增。

### 中央画布

继续编辑当前真实 Slidev 页面，不重新实现一套幻灯片渲染器。选框、拖动、尺寸、旋转、吸附、原位文字编辑及组件交互限制沿用现有实现。

画布适应顶部、左右栏、备注与底栏占用后剩余的矩形，保留实际幻灯片比例。位置换算继续以实际画布的 DOM 矩形为依据。视图变化不得改写页面 frontmatter 的 `zoom`。

首版提供自动适应和只读的当前显示比例，不新增手动缩放、画布平移或无限画布。收起侧栏和备注时重新适应剩余空间。

### 右侧属性

右侧是可以收起的详细设置区域，关闭面板后空间归还画布。默认跟随选择：选中元素时显示元素属性；没有选择时显示页面设置。布局、页面切换或动画命令可以显式打开对应详细面板，选中其他对象时不应无故打断正在使用的动画设置。具体选择规则由一个小型、明确的 UI 状态实现，沿用现有上下文，不增加通用插件系统或命令总线。

保留组件参数、自由定位与返回文档流、位置尺寸、布局参数等已有能力。源码、类名和源位置等技术内容放入可展开的高级区域，不删除高级编辑入口。

### 备注和写入反馈

把当前页备注从布局长面板移到中央画布下方，默认收起，底部状态栏提供直接显隐入口。底栏左侧显示当前页与总页数，右侧显示实际视图比例和适应窗口。首版不放置尚未实现的缩放滑块、幻灯片浏览视图或阅读视图按钮。复用现有备注读写语义，避免出现两个可同时修改同一备注的表单。

继续使用现有提交方式：原位文字通过已有应用操作写回，属性表单按当前触发方式写回。不增加整个文稿的待保存副本，也不添加没有真实语义的全局保存按钮。

可显示现有写入中状态及错误。不得仅因为 `busy` 变为 false 就显示“已保存”，也不得把写入文稿与 Git 同步混为一谈。请求重试、恢复队列、持久历史不在本次范围。

## 进入编辑和预览放映

保留已有 `E`、底部铅笔和右键入口；打开后统一进入完整界面，不同时维护旧版悬浮编辑器。

建议提供明确的 `?studio=1` 入口参数，方便浏览器书签、外部工作台或未来本地启动器直接打开编辑模式。普通入口保留已有开关偏好；显式参数在进入时优先，退出编辑或预览时同步移除或更新，防止刷新意外重新打开。所有路径遵循现有 Vite `base`，不硬编码工作台路径或域名。

“预览”在当前标签页收起编辑外壳、恢复正常幻灯片交互，并提供返回编辑入口；“放映”复用现有 Slidev/浏览器全屏能力，以当前页为起点。结束由 Studio 发起的放映后返回编辑，避免影响普通演示入口的全屏行为。原位文字编辑期间暂时禁用预览和放映入口，并提示先用已有工具条应用或取消；不增加草稿恢复或新的确认弹窗。

构建、导出、打印、嵌入与备注查看模式继续遵守现有 Studio 可用性边界。静态构建仍是播放文稿，不因此获得编辑能力。

## 实现边界与复用

| 部分 | 职责与已有基础 |
| --- | --- |
| 编辑外壳 | `StudioRoot`、`StudioToolbar`、`StudioDock`、`styles/studio.css`；安排页面区域、模式和可见命令 |
| 页面列表 | `PanelSlides`、`SlideThumbnail`；用现有页面操作，按需抽出顶部和列表共用的小段操作逻辑 |
| 属性与插入面板 | 复用 `PanelInspect`、`PanelLayout`、`PanelAnimate`、`PanelComponents`、`PanelAssets`；按界面需要拆分已有职责 |
| 画布与选区 | 复用 `useSlideCanvas`、`useSelection`、`useTransformGizmo`、`SelectionLayer`；适配新的可用区域 |
| 内容读写 | 保留 `useSlideSource`、`actions`、`client/md`、`useDeckApi`、现有 Node 插件和素材目录 |

外壳调用现有编辑动作和上下文，Markdown/Node 层不依赖工具栏或外部工作台。仅收敛实际需要复用的逻辑，不以重构名义新增状态层、持久模型、后端协议或数据库。

桌面窗口是主要使用场景。窗口变窄时先收起可选侧栏、让命令组合理滚动或折叠，保持画布可见；本次不建设手机触控编辑器。具体尺寸、断点、组件文件拆分及图标选择由实施者在现有结构内决定。

## 已知限制与后续候选

首版保留：页面新增、复制、删除和排序引发整页刷新及撤销历史清空；入口文件第一页不能移动或删除；跨 Markdown 文件不能拖动排序；隐藏页无法在现有列表恢复；部分复杂内容需通过 Markdown 编辑。

这些限制应在对应禁用状态、操作提示或说明中可理解，不能因界面变化暗示已获得完整 PowerPoint 行为。已有限制不自动触发新的恢复机制或数据模型。

多选、组合、批量对齐、跨页对象剪贴板、字体字号控件、隐藏页管理、手动缩放和桌面打包均为后续候选，需另行确认需求和路线。本次不处理发布、依赖升级或工作台集成改造。

## 验收与验证范围

首版完成标准是：在普通 Slidev 工程中进入完整编辑模式，左侧页面列表和右侧属性同时可用；顶部能执行所列已有操作；中央实际画布在各区域显隐后正确适应；备注有独立入口；可以预览、放映并回到编辑。上述过程不调用工作台或 Git 接口。

实施后集中运行相关已有测试、`pnpm test`、`pnpm typecheck`，并对 playground 做必要的编译检查。已有真实服务 QA 的运行要求先检查，不为本次布局更新自动搭建端到端环境。新增永久测试只针对关键新增行为或明确回归风险，不新增文案、样式、源码字符串断言或独立验证框架。

页面检查最多使用截图，覆盖正常桌面布局和较窄窗口；不自动点击、填写或执行交互流程。拖动、输入、插入、页面操作、放映返回等未经过实际操作的行为，在交付时明确标为待用户试用，不能以编译或单元测试通过代替体验验收。

## PowerPoint 界面对照依据

调研日期：2026-11-15。以微软官方说明中的 Windows 桌面版 Microsoft 365 / PowerPoint 2024 结构为主；同时查看官方普通视图示意和 Office 视觉更新配图。普通视图示意来自较早版本，只用于判断区域关系，不作为当前版本像素级外观依据。网页版简化功能区仅作为减少命令密度的补充参考。

- [普通视图及其他视图](https://support.microsoft.com/en-us/powerpoint/training/choose-the-right-view-for-the-task-in-powerpoint)：编辑区由左侧缩略图、中央当前页、下方备注组成，底栏提供常用视图入口。Studio 沿用区域分工，首版只展示已实现的视图操作。
- [功能区与上下文标签](https://support.microsoft.com/en-us/powerpoint/where-are-the-menus-and-toolbars)：命令按用途归类，组内可展开更多设置；选中某类对象后提供对应工具。Studio 使用分组命令和统一对象标签，并把已有页面切换与元素动画分开。
- [缩略图区域](https://support.microsoft.com/en-us/powerpoint/show-or-hide-slide-thumbnails)：桌面版支持左侧浏览与拖动排序，区域可调宽或收起。Studio 优先保证常驻浏览、缩略图占比和显隐，不要求本次实现所有桌面调整手势。
- [右侧格式设置示例](https://support.microsoft.com/en-us/powerpoint/create-columns-of-text-in-a-text-box-or-shape)：格式面板承接详细设置。Studio 的属性面板遵循这一职责，默认打开属于本项目的编辑便利性选择。
- [视图缩放和适应窗口](https://support.microsoft.com/en-us/excel/zoom-in-or-out-of-a-document-presentation-or-worksheet)：PowerPoint 在视图功能区和底栏提供缩放及适应窗口。Studio 首版保留已确认的自动适应与比例显示，手动缩放另行建设。
- [Office 视觉更新](https://support.microsoft.com/en-us/office/foundations-experiences/the-new-look-of-office)：新版配图继续使用标题区、标签和分组命令；主题支持多种外观。Studio 保持现有配色，不把橙红标题栏或固定浅色认作 PowerPoint 结构的必要条件。
- [网页版简化功能区](https://support.microsoft.com/en-gb/powerpoint/use-the-simplified-ribbon-in-powerpoint-for-the-web)：常用命令可直接显示，其余相关选项通过菜单展开。Studio 采用适合自身命令数量的紧凑分组，不新增“经典/简化”双套模式。
