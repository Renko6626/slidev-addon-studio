# 文字交互快速优化

用户要求迅速实施此前建议的第一轮与第三轮，沿用已确认的 Tiptap、Vue 和 Markdown/HTML 保存路线。

范围：首次双击按词选中（含中文），格式按钮不抢焦点，字段 Enter 返回文字、Esc 返回文字；普通 Markdown 列表接入富文本；段前段后间距；字号增减、当前字体预览；粘贴提供保留支持的源格式、匹配当前文字格式、仅文字。默认保留支持的源格式。

沿用现有模块和依赖；不改 frontmatter、任意组件或文本框尺寸模型，不新增恢复机制。源内容不能安全转换时继续回退。文本选区与整框作用范围沿用现有语义，Esc 仍提交并退出。

方案取舍：在现有文字命令和源码适配处扩展，改动小且保留旧文稿兼容；更换编辑器、统一对象存储或自动迁移组件会扩大范围，本轮不采用。

验证：复用现有富文本行为测试覆盖新命令、列表读写和选词；集中运行已有测试、TS、Vue SFC 检查与构建。不运行浏览器自动交互；真实 IME、剪贴板和鼠标手感留给试用。
