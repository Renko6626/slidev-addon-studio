# 桌面主页工程准备进度

用户要求：主页新建工程安装 pnpm 依赖时显示状态和进度条，避免长时间无反馈让人误以为卡死。

沿用当前 Electron runtime 的 `onStatus` 和 preload 状态事件，不新增接口通道、依赖或后台任务模型。主页采用不定量进度条，显示当前阶段、已用时间及 pnpm 最新输出；安装没有可靠的总百分比，故不估算百分比。相比只放动画，真实输出有助于确认下载/安装是否继续；无需引入可取消任务、超时恢复或重试队列。

runtime 以 append-only reporter 获取 pnpm 输出，使用 Node readline 分行；常见包计数显示为中文，其他输出作为详情。安装和启动编辑器使用不同阶段提示，错误延续现有处理。主页安装期间保留日志入口，查看日志不结束忙碌状态。没有新的旧数据兼容要求。

验证复用桌面 runtime 现有测试，补一个真实子进程输出转发用例；主页仅导航/初始化状态截图，不自动点击或填写。运行相关测试、脚本语法检查和项目类型检查。不打包、不发布，不做全新工程联网安装。
