# 人机协同制作与原生素材支持

目标：agent 负责复杂效果和逻辑，用户能在 Studio 完成位置、文案、素材微调。用户已确认素材采用浏览器原生支持与清晰提示，不引入自动转码依赖。

沿用现有 Vue 组件、字段元数据、runtime、public 素材与上传接口。不增加共享状态、服务或恢复机制；不改变工作台与桌面的 Slidev 版本。

- [x] 更新 agent 指南和桌面 AGENTS，附带可独立阅读的 studio-authoring skill；npm 打包包含 skill 与完整样例。
- [x] 增加人机协同样例：独立可拖文字、字段化图文组件、共用题目状态。样例仅使用公共包入口，不依赖仓库内部路径。
- [x] 素材分类统一；补音频和常见浏览器图片格式，保留原文件。图片单文件 32 MiB，音视频 128 MiB；较大素材可直接放 public。拒绝 HEIC/TIFF 等时说明转换办法。
- [x] 通过现有组件目录增加 StudioMedia，使用原生 audio/video 与 active 控制；属性表单、替换文件、加载/播放失败提示。离开当前播放页暂停并复位，不增加跨页音乐功能。
- [x] 复用现有素材测试与 SFC 加载辅助，覆盖音频保存/分类、插入源码、媒体编辑静默/切页暂停/播放失败提示；文档不新增永久测试。
- [x] 统一运行相关测试、类型检查、样例根路径与子路径构建、技能校验、包内容检查。检查本地 53.0 适配；准备新 npm 版本与更新说明。

验证范围：不自动点击或填写浏览器表单，不将构建或模拟媒体测试当作 Windows 编码播放验收。发布前检查包内容与验证证据；不修改部署入口。
