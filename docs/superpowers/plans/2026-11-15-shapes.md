# Built-in Shapes Implementation Plan

> 使用 executing-plans 在当前会话执行；已有文字改动原样保留，不提交、合并或发布。

**Goal:** 内置可画布编辑的 SVG 预制图形。
**Architecture:** 放映组件与编辑器分离，复用 v-drag 和 Markdown 历史。
**Tech Stack:** 现有 Vue、TypeScript、Slidev、VueUse；无新依赖。
**Spec:** `docs/superpowers/specs/2026-11-15-shapes-design.md`

## Constraints
按类型提供手柄，不开放顶点编辑；不新增服务器和持久对象模型；浏览器仅截图。
