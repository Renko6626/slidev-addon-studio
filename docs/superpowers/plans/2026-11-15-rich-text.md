# Studio 文本框富文本实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Studio 文本框获得局部、光标与整框格式，以及统一文字工具和编辑历史。

**Architecture:** Tiptap 管理文本框内文；现有 InlineEditor 管理应用、取消及旧内容；源码仍保存原生 HTML 内文，不改变根 div 的定位。

**Tech Stack:** Vue、TypeScript、Tiptap/ProseMirror 3.x、现有 Vitest；jsdom 26 用于实际 Editor 的单元检查。

**Spec:** `docs/superpowers/specs/2026-11-15-rich-text-design.md`

## Global Constraints

- 用户已授权计划后直接实施，不追加批准步骤。
- 只接管 Studio 文本框，不自动转换 Markdown 或组件。
- 保留未提交的 `playground/slides.md` 用户改动，不将其纳入提交。
- 不增加请求队列、恢复机制、持久对象模型、后端协议或云服务。
- 浏览器只截图，实际输入、焦点与拖动留给用户试用；集中验证。

## Review Focus

- 格式按钮、字体输入、颜色菜单不会结束正在进行的文字编辑；命令仍作用于原文字选区。
- Ctrl+Z 在文字编辑中不同时撤销文稿，中文组合中的 Esc/Enter 不触发应用。
- 插入占位全选、双击进入、F2、外部点击切换保持现有对象流程。
- 自动新增 p/list/span 不改变原文框位置；静态展示保留段落、字号、颜色和列表样式。
- 不支持的 HTML 不静默丢弃；不修改时退出不重写原文，取消恢复编辑前内容。
