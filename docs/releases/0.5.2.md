# Studio 0.5.2

本版本统一桌面和线上共用的 Studio 制作能力。桌面壳单独维护版本；已有工程需要明确升级自己的 Studio 依赖，源码合并或更新工作台不会自动改写文稿环境。

- 富文本支持 Studio 文本框和可安全读取的普通标题/段落；支持字符格式、字体、段落及列表。
- 文本框支持自动高度、固定大小、垂直对齐、内边距和溢出提示；布局修改保留已有 Vue 插值。
- 字体选择器支持搜索、样字和工程字体导入。字体文件与标准 CSS 随工程和网页构建携带，已有外链配置保留。
- 文件页支持源码工程 ZIP、PDF/PNG/图片型 PPTX 导出入口；新桌面宿主另提供工程 ZIP 导入和可选网页播放包。
- 源码侧栏提供页面、组件和工程位置，方便人与 coding agent 接续制作。
- 线上工作台可通过启动上下文显示活动名、个人草稿说明和返回活动入口。返回前先保存；保存不等于 Git 同步或提交审核。

线上继续使用自己的 Slidev 53 与子路径补丁；普通 addon 和桌面使用者不需要工作台。工程字体不包含系统字形扫描或自动转换，图片型 PPTX 仍不能在 PowerPoint 分别编辑对象。Windows 原生行为、输入法和真实浏览器制作流程需要实际试用。
