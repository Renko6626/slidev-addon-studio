# 0.5.0

- 选择题属性面板支持增删选项，同时更新题目规则与内置选项按钮；保留其余选项的编号、内容和布局。
- 桌面窗口将原生窗口按钮叠加在 Studio 标题栏，移除重复菜单行。日志与工程操作集中到“文件”页。
- “文件”页可以打开工程根目录，并提供 coding agent 的工作目录提示与项目内 skill 路径。
- addon 与桌面统一使用 X.Y.Z 版本号。默认构建联网版，离线版通过 `--offline` 单独构建。
- 本地脚本统一收集 Windows x64 ZIP、addon tgz 与 SHA256 校验表。GitHub Release 保持手动上传，CI 不构建或传输桌面大文件。

## 使用

联网版：完整解压 ZIP 后运行 `Slidev Studio.exe`，首次准备工程依赖需要联网。
离线版：只有明确标记 `offline` 的 ZIP 随附标准工程依赖；外链资源、在线服务及新增依赖仍可能需要联网。

现有工程不会自动升级。桌面打开旧工程时可选择启用随附 Studio；保留文稿、素材与原有布局。

构建和发布命令见 [desktop/README.md](../../desktop/README.md)。Windows 原生界面与实际设备行为需要实机试用，本地静态检查和打包不能代替该验证。
