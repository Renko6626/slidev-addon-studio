# Slidev Studio 客户端 0.5.2

Windows x64 便携版，随附 Studio 编辑器 0.5.2。完整解压后运行 `Slidev Studio.exe`，无需另装 Node 或 pnpm。

## 新增与改进

- “版本与更新”可离线查看本版说明，手动检查稳定客户端，并打开新版的更新说明与下载页。打开工程后可从原生“帮助”菜单进入，按 Alt 显示菜单。
- 随附编辑器支持富文本、自动高度及固定大小文本框、垂直对齐、内边距和工程字体导入。字体文件随工程及网页构建携带。
- 支持工程 ZIP 导入和导出、原生工程管理与运行日志，以及可选的 Windows 网页播放包导出。

## 下载与升级

- 轻量版首次准备缺少的依赖时需要联网。可选离线完整版额外随附标准工程依赖；外链素材、网络字体及自定义新增依赖仍可能需要联网。
- 下载后解压到新的可写目录，运行新版，再打开原工程。不要只替换 exe，也不要混合覆盖旧客户端目录。
- 客户端升级保留已有工程的 Studio 版本。需要新编辑能力时，另选“更新工程内 Studio”；此操作只更新所选工程的编辑器包。

## 已知限制

- 客户端查新需要访问 GitHub；网络失败时可继续编辑，稍后手动重试或打开发布页。查新不自动下载、安装或替换客户端。
- PDF、PNG 和图片型 PPTX 可由导出入口生成；图片型 PPTX 的文字和对象不能在 PowerPoint 中单独编辑。
- Windows 解压启动、原生窗口、保存重开、字体及网页播放包仍需实机试用。取得反馈前按预发布包交付，不能用 Linux 检查代替 Windows 验收。
