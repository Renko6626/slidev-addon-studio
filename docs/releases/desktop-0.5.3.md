# Slidev Studio 客户端 0.5.3

Windows x64 轻量便携预发布，随附 Studio 编辑器 0.5.3。完整解压到可写目录后运行 `Slidev Studio.exe`。

## 新增与改进

- 新图标用于欢迎页、窗口标题栏、任务栏和可执行文件。
- 欢迎页缩短了常驻说明。安装进度下方可以直接打开运行日志，联网和故障排查说明收进“启动帮助”。
- 随附 Studio 支持新增页热更新、查看组件 Vue 源码，以及更紧凑的工具栏和文件页。

## 下载与试用

- 轻量版首次准备缺少的依赖时需要联网。请解压到新目录后运行，已有工程保留自己的 Studio 版本。要试用新版编辑器，可以新建工程，或手动更新选中的已有工程。
- Windows 实机验收仍待完成，主要包括解压启动、任务栏图标和编辑后保存重开。
