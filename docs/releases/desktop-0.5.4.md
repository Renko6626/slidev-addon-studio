# Slidev Studio 客户端 0.5.4

Windows x64 便携版提供轻量 ZIP 和完整离线 ZIP。完整解压到可写目录后运行 `Slidev Studio.exe`。

## 完整版的依赖复用

- 工程和客户端位于同一卷时，多个工程可以共享随包依赖文件。客户端位于 C 盘、工程位于 D 盘时，首次安装会补齐 D 盘的 pnpm 缓存，其他 D 盘工程可以直接复用。运行日志会显示实际使用的缓存目录。
- 匹配随包版本和锁文件的标准工程支持离线新建、另存和导入。每个工程保留自己的锁文件和 Studio 归档，工程 ZIP 可以交给另一台电脑继续编辑。
- 目标卷无法共享缓存时，客户端从随包资源准备工程。磁盘空间不足时可以腾出空间，重新打开工程继续准备。

在 Linux 的两个 ext4 卷上使用 Windows x64 依赖测试，第二个标准工程新增依赖占用约 25 MiB，逐工程复制约 544 MiB。首次和第二次安装的 pnpm 下载数均为 0。原生 Windows 双 NTFS 卷仍待实机验证。
