# 0.4.0-renko.1

版本：`0.4.0-renko.1`，2026-11-16。已发布到 npm 并设为 latest；公开版本与交付 tgz 的 SHA-512 一致。对应标签为 `v0.4.0-renko.1`。

## 人机协同制作

agent 完成效果、业务逻辑和初稿排版，人在 Studio 拖动对象、微调文字和替换素材。随包提供 `skills/studio-authoring/SKILL.md`，也可直接让 agent 阅读；桌面新工程的 AGENTS 已指向该入口。不会自动修改机器上的 agent 配置。

`examples/human-agent/` 是可复制运行的完整工程：独立文本框、带可编辑图文的嘉宾卡、共享判题与计数、自生成 MP4/WAV。示例只使用公开 runtime，无需克隆源码仓库。

## 编辑器与交互

本版包含此前源码阶段的工作区、富文本、文本框/图片、基础形状、多选对齐、同容器图层、背景和图片位置、工程 ZIP、单选/多选题页、组件字段、应用级 Pinia 与独立预览状态。详细操作见仓库 README 与使用指南。

新增 StudioMedia：原生 audio/video，文件替换、封面、自动播放、控制条、循环、静音、音量及起播时间。编辑与辅助视图静默；离开当前播放页暂停并复位。自动播放失败有手动入口。

素材库支持音频及额外图片格式；图片限制 32 MiB，音视频 128 MiB。原文件保留，无自动转码。编码仍须在目标设备确认，格式和限制见 [素材说明](../custom-code/media.md)。

## 升级

```bash
pnpm add -D slidev-addon-studio@npm:@renko_1055/slidev-addon-studio@0.4.0-renko.1
```

已有工程先保留文稿与素材；本命令只更新依赖，不迁移内容。Vue 需要 ^3.5.11；直接编写 Pinia store 的工程声明 pinia@3.0.4。不要为了更新 Studio 顺带升级 Slidev、主题或 Vue 大版本。

相较旧实验源码：`dispatchInteraction(signal)` 改成 `dispatchInteraction(runtime, signal)`；题目规则只存 mode 与 `{ id, correct }[]`，题干用普通文本框，选项和反馈文案属于各自组件。已移除 StudioQuestionTitle，不提供旧实验题页自动迁移。旧页面的原生媒体与 SlidevVideo 保持原行为，编辑静默需按需替换为 StudioMedia。

工作台活动依赖固定在各自仓库中；发布 npm 不会自动更新已有活动。桌面新包需重新打包，已有 ZIP 不会自动升级。
