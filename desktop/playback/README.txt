网页播放包（Windows x64）

完整解压后双击 start.cmd，在系统默认浏览器中播放。无需安装 Studio、Node 或 Rust。保持服务器窗口打开，结束后关闭浏览器和服务器窗口。

web 目录是导出时的网页成品。动画、答题和音视频沿用原工程的运行方式；它不提供源工程编辑，修改原工程后需要重新导出。演讲备注默认不包含在网页包中。

本地图片、音视频与构建生成的脚本、样式随包提供。网络字体、外链素材和远程业务服务仍可能需要联网；导出不会自动抓取这些资源或替换作者的字体。

默认地址为 http://127.0.0.1:8080/，只在本机提供文件。如果浏览器打开过早，请稍等后刷新。如果端口已被其他程序占用，可用文本编辑器修改 start.cmd 中的 STUDIO_PLAYBACK_PORT，或停止你确认不再使用的旧服务。本包不自动关闭其他程序，也不安装系统服务或设置开机启动。

如服务器窗口立即关闭，请在解压目录打开命令提示符，手动运行以下命令查看错误：
miniserve.exe web --index index.html --spa -i 127.0.0.1 -p 8080

媒体实际解码与自动播放取决于浏览器和设备；必要时手动点击播放。
